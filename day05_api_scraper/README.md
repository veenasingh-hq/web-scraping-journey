# Day 05 - Public API Data Extractor

A Python-based API data extraction project using Requests and Pandas.

This project demonstrates how to retrieve structured JSON data from a public API, process the required fields, and export the final data into a CSV file.

## 🌐 API Used

JSONPlaceholder

https://jsonplaceholder.typicode.com/posts

JSONPlaceholder is a free public API commonly used for testing and learning.

## 🎯 Project Goals

The project demonstrates:

- Making API requests
- Understanding JSON responses
- Extracting required fields
- Using query parameters
- Handling HTTP errors
- Processing API data
- Removing duplicate records
- Exporting data to CSV
- Basic logging
- API pagination concepts

## 🛠️ Technologies Used

- Python
- Requests
- Pandas
- JSON
- CSV
